# Micro Mac Apps

A collection of small macOS apps and utilities. Each project has its own README with build instructions and limitations.

- [Usage](apps/usage/README.md) — tracks Codex, Claude Code, and Google Antigravity allowances in the menu bar and widgets. [MIT licence](apps/usage/LICENSE).
- [Corner Match](apps/corner-match/README.md) — native window corners for InDesign.
- [FocusBar](apps/focus-bar/README.md) — a menu bar reminder for your current focus.
- [Keyboard Power](apps/keyboard-power/README.md) — adjusts keyboard backlight inactivity by power source.
- [InDesign Appearance Sync](apps/indesign-appearance-sync/README.md) — follows the macOS light and dark appearance in InDesign.

Projects are independent; building one does not build or install the others.
